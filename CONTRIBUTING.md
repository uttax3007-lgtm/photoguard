# Contributing

Thanks for taking an interest in this PhotoGuard fork.

This repository builds on the PhotoGuard research implementation published by MadryLab. Please keep upstream attribution and license notices intact when making changes.

## Before making a change

- Check whether the issue also exists in the upstream repository.
- Keep pull requests focused and explain the motivation for each change.
- Avoid unrelated formatting or large dependency upgrades in research notebooks.
- Do not commit model weights, private images, credentials, API tokens, or generated datasets.

## Reproducibility

For changes that affect experiments or model behavior:

- State the Python, PyTorch, Diffusers, and CUDA versions used.
- Include the command or notebook steps needed to reproduce the result.
- Record relevant model identifiers and configuration values.
- Explain hardware requirements and known limitations.
- Do not describe a result as a security guarantee.

## Pull requests

A useful pull request includes:

1. A short description of the problem and proposed change.
2. The files or workflows affected.
3. Steps used to test the change.
4. Any compatibility notes or limitations.

Please preserve the original research citation in the README when redistributing or extending the research code.
